# 私人文件工作区

在任务面板创建「办公」任务，写明需要的成果。例如「检索太阳能电池的基本原理，生成 brief.md，并在 terms.csv 列出三个关键概念」。任务列出已执行的动作，文件列表提供独立下载入口。

创建时可附带 1 到 4 份 UTF-8 文本，每份最多 24 KiB，文件名不可重复。例如上传具有「地区、收入」两列的 sales.csv，再要求「统计 sales.csv 的收入总额、最小值和最大值，输出 result.md」。任务会先处理点名的附件。没有点名时会检查全部附件。文本附件供模型阅读，CSV 用本地计算工具得出数据行数、有效数字个数及每列的合计、最小和最大值，再把统计传给模型撰写报告。可选容器模式及数字解析规则见[表格工具](table-tools.md)。

模型每次选择一个动作。它能列出当前任务的文件、读取文件、写入完整文本、通过配置的搜索服务检索公开资料，最后提交交付摘要。每轮最多六步，至少成功写入一份文件才可结束。每个任务最多保留十二份文件，每份上限 24 KiB，支持 Markdown、CSV 和纯文本。写入同名文件会替换该文件的内容。CSV 写入会检查表头、数据行和列数，再按标准 CSV 规则处理引号与逗号。简单任务若明确列出要创建的文件，文件全部写入后，系统直接根据实际文件名生成回执。

文件正文位于 SQLite，使用任务 ID 与所属账号确定读取权限。周期任务可继续处理前一轮留下的文件。删除任务时清除该任务的所有文件与步骤。模型选择、执行结果和文件写入均有持久记录。暂停后从已保存的动作恢复。进程中断时，尚未保存回复的模型请求可能已经计费，已经发出但尚未记录结果的公开检索也可能重新执行。每个规划请求通过与聊天相同的额度账本。

## 文件交付与验证

任务执行时读写 Markdown、纯文本与 CSV。下载时可以保留原文件，或将文本成果导出为 Word（.docx）、将 CSV 导出为 Excel（.xlsx）。Word 导出支持标题与列表，Excel 将单元格作为文本保存，保留前导零。导出作用于现有文本内容；任意 Word 模板回编、编辑已有 Excel 工作簿、公式计算均超出这个工作区当前的编辑范围。

另一次真实联测通过 Web API 上传包含引号内逗号的 CSV，输入三笔收入 12.34、0.76、15.90。本地 Qwen2.5-0.5B 在读取确定性统计后生成 totals.md；从下载接口取得的 Markdown 及 Word 文档均记载总额 29.00、最小 0.76、最大 15.90、共 3 行。

多文件测试覆盖两个具名成果齐备后生成回执、查询其他账号文件、恢复已保存动作、CSV 行列一致性，以及逗号、引号的转义。用本机 Qwen2.5-0.5B 的一次实际运行生成了 brief.md 和 orbit.csv，后者可以解析为表头和一行数据。模型在该次运行中自行增加了一列，填入的天文数据也有错误。格式检查能验证文件结构，事实与字段要求需要结合任务资料复核。[办公代理测试](../tests/test_office.py) · [导出测试](../tests/test_exports.py)
