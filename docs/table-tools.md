# 私有 CSV 汇总

工作台可以统计 CSV 中每列的数值之和、最小值和最大值。工具还返回每列数值、空值、其他内容的个数，便于判断汇总覆盖了哪些行。

## 表格规则

- 输入为 UTF-8 逗号分隔文本，支持 BOM、双引号转义、带换行的引号字段。第一个非空记录作为表头，其后最多 4,096 条数据记录。输入上限为 24 KiB、256 列，每个字段最多 2,048 个字符。
- 空白物理行跳过。数据行短于表头时，缺少的列记为空值。行宽超过表头时返回错误。只有表头的文件可以汇总，行数为零。
- 输出的 `columns` 按输入顺序排列，保留重名表头。空表头依次采用其实际列号，如 `列3`。
- 数值支持正负号、小数点和科学记数法。数字最多 256 个有效位，十进制系数的指数介于 −256 与 256。超出范围会报错。数值比较和求和使用十进制运算，结果作为字符串返回，零统一显示为 `0`。
- 空字符串及纯空白字段计入 `empty_count`。日期、货币符号、千位分隔符、`NaN`、`Infinity` 和表格公式按文本计入 `other_count`。只有有限数值计入 `numeric_count` 并参与汇总。纯文本列和空列的 `sum`、`min`、`max` 为 `null`。
- `kind` 取值为 `number`、`mixed`、`text` 或 `empty`。例如一列包含 `0.1`、`0.2` 和 `未结算`，类型为 `mixed`，合计为 `"0.3"`，另有一条文本记录。

## 运行

默认配置为 `ECHO_TABLE_RUNTIME=local`，直接使用 Python 标准库。运算只解析 CSV，结果通过办公工具返回。

若需将运算放在独立容器中，在运行工作台的 Linux 主机进入项目根目录，构建本地镜像并记录不可变 ID。

```sh
docker build -t echo-assistant .
docker image inspect --format '{{.Id}}' echo-assistant
```

在工作台的环境变量中设置 `ECHO_TABLE_RUNTIME=container`，将上一条命令输出的完整 `sha256:` ID 填入 `ECHO_TABLE_IMAGE_ID`，再重启工作台。升级时重新构建镜像并更新 ID。此模式要求宿主机的 Docker CLI 可用，工作台进程可以访问本地 `/var/run/docker.sock`。标准应用容器内默认使用 `local` 模式。

每次汇总运行独立的非特权容器，使用只读根文件系统、独立无网网络、空的额外 capabilities、`no-new-privileges` 和 UID/GID 10001。限制为 0.5 个 CPU、128 MiB 内存、32 个进程、20 秒执行时间和 512 KiB 输出。CSV 通过标准输入传入，工具使用固定程序入口，容器退出后删除。容器启动、资源限制或镜像检查失败时，调用返回错误。
