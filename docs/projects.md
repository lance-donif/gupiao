# 私人项目

项目把多次任务要用的资料和交付文件放在同一处。每个项目属于创建它的工作区。你可以在 Web 的项目面板中建项目、保存文件、读取旧版本，并用选中的文件创建办公任务。

## 从资料到交付

1. 创建项目「季度报告」，保存文件 `销售.csv`。新项目的首个文件从版本 1 开始。项目文件支持 UTF-8 的 Markdown、TXT 和 CSV，每份最多 24 KiB。
2. 在新办公任务中选择项目和当前版本的 `销售.csv`，要求「计算收入总额，在 result.md 中写出结果」。任务可以合计使用最多四个项目文件及上传附件。工作台将输入复制到任务自己的文件工作区。
3. 任务运行期间，项目资料仍可以编辑。任务读取创建时的副本，项目页会列出这项任务及其当时选用的文件版本。后续任务可使用新版资料。
4. 任务完成后检查输出，再选择本轮实际写出的 `result.md`，显式发布到项目。可选择目标文件名。发布会记录当时的内容、SHA-256、来源任务 ID 和运行轮次。定时任务开始下一轮后，需要重新确认本轮的成果。
5. 查看项目中交付文件的版本记录。手工编写和任务发布的版本都会保留，历史版本可打开阅读。

## 并发编辑和删除

编辑已有文件时，服务会校验打开文件时的版本。若其他窗口已经更新，保存会返回 HTTP 409。此时刷新当前文件并重新检查自己的修改。创建任务时也会核对所选版本；若提交后网络中断，使用相同请求编号和相同参数重试，可取回先前创建的任务。

删除项目文件会清除它在项目中的正文和历史版本。为防止旧标签页误覆盖重建的文件，系统按项目保留已删除版本的最高编号，已删除文件名释放占用的名额。再次新建同名文件时使用 `expected_version=0`，服务返回的版本号会高于删除前的版本。所以初次使用新文件名时也可能得到大于 1 的版本号。文件名称按大小写折叠比较。

删除项目会清除项目文件、版本及项目内的任务关联。任务中的输入副本和已生成成果保存在各自的任务中，需要时可单独删除任务。已发布到项目的文件拥有独立副本，删除来源任务后仍可读取。

## 容量

每个工作区最多有 64 个项目，每个项目最多有 128 个当前文件。单个文件可保留 64 个版本，每个项目所有版本的正文按 UTF-8 字节累计，最多为 8 MiB。保存编辑和发布成果共用这些上限。达到上限后，已有正文和历史版本仍可打开。需要继续编辑时，可以另存新文件，或导出需要的版本后显式删除旧文件以释放容量。

## 服务接口

以下接口使用 Web 工作区令牌。文件名放入 URL 时应进行路径段编码。

| 方法和路径 | 请求或用途 |
| --- | --- |
| `POST /api/projects`、`GET /api/projects` | 提交 `{"name":"季度报告"}` 建立项目，或读取当前工作区的项目列表。 |
| `GET /api/projects/{id}`、`DELETE /api/projects/{id}` | 查看项目、当前文件及附属任务，或删除项目。 |
| `PUT /api/projects/{id}/files/{name}` | 提交 `content` 和 `expected_version`，创建时预期版本为 0。 |
| `GET /api/projects/{id}/files/{name}` | 返回当前文本和版本元数据，查询参数 `version` 可指定历史版本。 |
| `GET /api/projects/{id}/files/{name}/history` | 按版本从新到旧列出文件元数据。 |
| `DELETE /api/projects/{id}/files/{name}?expected_version=N` | 当前版本与 N 相符时删除该文件。 |
| `POST /api/tasks` | 除任务说明外，传入 `kind="office"`、`project_id`、`project_files=[{"name":"销售.csv","version":1}]` 和唯一的 `request_id`。 |
| `POST /api/projects/{id}/publish` | 提交 `task_id`、`source_name`、`source_run_id`、`target_name` 和目标的 `expected_version`。 |

项目创建、版本保存、输入复制和文件发布都是本地 SQLite 操作。只有模型实际执行任务时才可能产生模型费用。[办公任务](office.md) · [额度与核账](budget.md)

## 复验记录

在临时工作区通过 HTTP 上传第 1 版 `收入.csv`，内容是 12.30 和 0.70。创建选用该版本的办公任务后，将项目文件改成金额为 999.00 的第 2 版，再启动任务。本机 Qwen3.5-2B 使用任务副本与十进制汇总工具，在 `totals.md` 中写出「合计收入为 13 元」。经显式发布，以 `已审.md` 从项目读回的正文与任务成果相符。这次运行的本地应用账本预估及待核金额均为 0 美元。[项目回归测试](../tests/test_projects.py)
