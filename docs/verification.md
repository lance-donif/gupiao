## 独立监督与费用

监督智能体以空白会话启动，只收到验收任务。它独立运行测试，对照腾讯文档审查 QQ 协议，核验所有者隔离，并解包检查了真实 DOCX 和 XLSX。它发现已完成一轮的定期任务无法从 QQ 暂停下一轮，以及执行中的一次性任务在 Web 缺少暂停入口。这两项已修正。

本次应用验收调用本机模型，应用账本按零美元费率记账；QQ 出站使用模拟腾讯服务。没有可供核对的付费供应商项目、平台账单、真实 QQ 机器人或客户端回执。会话本身、宿主计算和电力等成本无法从应用账本推算。50,000 美元是应用可配置的累计最高额度，本次没有达到该金额的付款或消耗凭证。[核账口径和命令](budget.md)

## 项目、可核查的研究引用与 Linux 图形编辑器

- 将第一轮 Qwen 报告和当时的摘录原样回放。系统提示「10,000 倍」没有出现在所引的第二条摘录，并展示第一条中包含这个数字及「速度下限」的原句。这项检查比对百分比、百分点、倍数等数字和单位，不判断语义是否正确，也不自动替换引用。另用 Qwen3.5-2B 和实时中文维基百科从头运行，完成两次模型调用，实际读取两篇导语，导出的报告随附本轮资料摘录。Web 可展开来源，QQ 私聊或群内可用 `/来源 1` 核对当前对话的摘录。
